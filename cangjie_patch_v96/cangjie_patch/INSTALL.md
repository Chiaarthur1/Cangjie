## 2. Установка (5 минут)

```bash
# 1) распаковать исходный проект (если ещё не распакован)
tar xzf cangjie_ssh_offline_bundle.tar.gz
cd cangjie_project

# 2) наложить патч
cp ../cangjie_patch/code/*.py .
cp ../cangjie_patch/data/cangjie_paleo_templates_*.npz data/
cp ../cangjie_patch/data/calibration_v96.json data/

# 3) проверить, что всё встало
python3 cangjie_rebuild_banks.py --component --era KAISHU   # должно взять кэш
python3 -c "import cangjie_photo_decoder, cangjie_whole_glyph; print('OK')"
```

> **Важно:** старые `calibration_v94.json` можно оставить — матчер сам берёт
> самую свежую по номеру версии. Но `calibration_v96.json` положить
> обязательно: без неё уверенность будет откалибрована под старые
> дескрипторы.

python3 cangjie_verify_fullchar.py --era KAISHU

## 6. Что обучать (и что НЕ обучать сейчас)

### 6.1 Датасет из музейных каталогов — УЖЕ РАБОТАЕТ

`cangjie_museum_dataset.py` качает **настоящие** фотографии древних
надписей с Wikimedia Commons (лицензии Public Domain / CC0 / CC BY),
накладывает реальные деградации носителя (кость, бронза, 拓片, бумага)
и пишет манифест с лицензиями.

```bash
# посмотреть, что найдётся, ничего не качая
python3 cangjie_museum_dataset.py --search "oracle bone script" --limit 30 --dry-run

# собрать датасет
python3 cangjie_museum_dataset.py \
    --search "oracle bone script" \
    --search "bronze inscription china" \
    --search "seal script chinese" \
    --search "stele chinese inscription" \
    --limit 60 --out ./data/museum_dataset
```

Результат:
```
data/museum_dataset/
├── manifest.jsonl        — по строке на файл: источник, лицензия, автор, варианты
├── images/<id>.png       — оригинал (обрезанный до 2048px)
├── images/<id>_BONE.png  — та же кость, но с деградацией
├── images/<id>_BRONZE.png
├── images/<id>_TOPIAN.png
├── images/<id>_PAPER.png
└── LICENSE_SUMMARY.json  — сводка по лицензиям (обязательно для публикации)
```

**Важно про лицензии.** Wikimedia требует указания автора и лицензии при
публикации. Всё это уже записано в `manifest.jsonl` и
`LICENSE_SUMMARY.json` — не выбрасывай их, если планируешь публиковать
датасет или модель на нём.

Wikimedia режет частые запросы (429) — в скрипте уже есть rate limiting
и ретраи с backoff, но массовую закачку лучше запускать ночью.

### 6.2 Сейчас обучать НЕЧЕГО

| Модель | Размер чекпойнта | Вердикт |
|---|---|---|
| D-FINE / RT-DETR детектор | **44 КБ** | Это **заглушка**, не веса. Обучать бессмысленно |
| CoT-корпус | 45 записей | Это seed, а не датасет |
| Банк шаблонов | пересобран | Пересборка — не обучение, это рендер |

### 6.3 Правильный порядок

```
1. Датасет реальных фото (музейные каталоги)   ← СДЕЛАНО: скрипт готов, 15 фото собрано
2. Разметка боксов компонентов на этих фото    ← СЛЕДУЮЩИЙ ШАГ (нужен ручной/полуавтомат.)
3. Детектор на этом датасете (GPU-станция)
4. CoT-корпус: дообучение на ~500+ примерах
5. Ноут на сутки — только дообучение головы (backbone заморожен)
```

### 6.4 Про «поставить ноут на сутки»

Правило простое: **если модель не влезает в 8 ГБ VRAM — на CPU она
не обучится вообще.** Поэтому:

- Детектор и LoRA — на твоей Graph Station (GPU);
- На ноуте реально только **дообучение головы** при замороженном
  backbone — это укладывается в сутки на CPU;
- На CPU полное обучение 7B — это дни, не часы. Не трать на него ноут.

### 6.5 Что обучать на GPU-станции (конкретно)

| Задача | Скрипт | Данные |
|---|---|---|
| Детектор компонентов | `cangjie_rtdetr_train.py` | размеченные боксы компонентов на `data/museum_dataset/` |
| YOLO-альтернатива | `cangjie_yolo_factory.py` | то же в формате YOLO |
| CoT-дистилляция | `cangjie_distillation_cot_pipeline.py` | `data/cangjie_verified_cot_corpus.jsonl` (45 записей — мало, надо расширять) |

## 7. Банк полных знаков (не вошёл в пакет)

Банк полных знаков (97 431 знак × 4 эры, ~130–180 МБ на эру) не поместился
в пакет по размеру. Собрать у себя:

```bash
python3 cangjie_rebuild_banks.py --fullchar --all --data-dir ./data
```

Время: **~15–20 минут на эру**, 4 эры ≈ 1–1.5 часа. Пока банк не собран,
`cangjie_whole_glyph.py` честно вернёт `UNAVAILABLE` — система при этом
работает, просто без прямого опознания целого знака.

## 9. Хрупкие места — не ломай

1. **Рендер банка, бенчмарка и калибровки обязан совпадать.** Если поменял
   рендер в одном — правь во всех трёх, иначе KAISHU упадёт в 0.0 при
   полностью рабочей системе (проверено на себе).
2. **`DESCRIPTOR_VERSION`** в `cangjie_paleo_matcher.py` — меняешь
   дескриптор → поднимай версию, иначе старые кэши подхватятся молча.
3. **Калибровка привязана к дескриптору.** Сменил рендер → переобучи:
   `python3 cangjie_calibration.py --data-dir ./data --out ./data/calibration_v97.json`
4. **`cangjie_paleo_matcher.py` не имеет CLI.** Не пытайся запустить его
   с `--build` — он молча выйдет с кодом 0. Используй
   `cangjie_rebuild_banks.py`.
