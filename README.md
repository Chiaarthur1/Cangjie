# Project Cangjie (仓颉)

> **Палеограф на ИИ**: по фотографии древнего китайского знака программа отвечает,
> **что это за знак, как он мог читаться и что означал** — по правилам китайской
> письменности (六书), а не «выдумкой» нейросети.

Проект распознаёт **甲骨文 / 金文 / 篆书 / 楷书** (кости, бронза, эстампажи, бумага)
и выдаёт объяснимое «палеографическое досье» с опорой на реальные источники
(Unihan, CHISE IDS, Baxter–Sagart, граф знаний).

---

## ✨ Ключевые особенности

- **Фото → досье.** Загрузите снимок древнего знака (+ опционально контекст находки:
  эпоха, носитель, место) — получите знак, чтение (пиньинь + средне-/древнекитайское),
  значение, разбор состава (IDS) и структуру.
- **Защита от галлюцинаций.** Каждый факт в досье опирается на ребро графа знаний
  (`СОСТОИТ_ИЗ`, `ЧТЕНИЕ`, `ГЛАССА`, `СЭШЭН`, `ПРЕЦЕДЕНТ`) с указанием источника.
  LLM рассуждает строго по этому списку, а не «додумывает».
- **Честность.** Если знак не узнан — статус `UNRECOGNIZED`, а не случайная догадка.
  Метрики замеряются, а не заявляются.
- **Выбор модели.** Детектор (`auto|rtdetr|yolo|pixel|none`), матчер
  (`chamfer_hog|embedding`), LLM (`none|ollama|vllm`). Без GPU/весов — честный
  fallback на пиксельный путь.
- **Полная панель управления** (7 вкладок): Декодер, Студия, Дуэль агентов, Модели,
  Обучение, Данные, Eval+Настройки.
- **Работает без GPU.** Пиксельный путь (Chamfer + HOG) и CPU-эмбеддинги работают
  на любом компьютере; нейросетевые пути подключаются при наличии обученных весов.

## 🚀 Установка

```bash
cd cangjie_project

# 1) виртуальное окружение
python3 -m venv .venv && source .venv/bin/activate

# 2) базовые зависимости (95% функционала)
pip install numpy pillow opencv-python networkx

# 3) для обучения детектора / эмбеддингов
pip install torch torchvision ultralytics
```

Данные (Unihan, CHISE IDS, Baxter–Sagart, MakeMeAHanzi) — в `data/` либо скачиваются
скриптом `download_datasets.sh`.

## 🎬 Быстрый старт

### Распознать фото знака

```bash
python3 cangjie_photo_decoder.py \
    --photo photo.jpg \
    --context "Кость гадателя, династия Шан, Аньян" \
    --output ./out --json
```

Выдаёт JSON-досье: `recognition_status`, `reconstructed_deep_ids`,
`paleographic_decoding` (чтение/значение/обоснование), `knowledge_graph_context`,
`model_selection`.

### Запустить веб-панель

```bash
python3 cangjie_ui_studio.py --serve --port 8080
# → http://localhost:8080
```

### Единый конфиг

```bash
python3 cangjie_config.py --show            # весь конфиг
python3 cangjie_config.py --machine auto    # авто-выбор железа
python3 cangjie_config.py --set detector.backend=pixel
python3 cangjie_config.py --validate
```

## 🎛️ Панель управления

| Вкладка | Назначение |
|---|---|
| **1. Декодер** | фото/IDS → досье |
| **2. Студия** | фото-сканер, ручное рисование штрихами и радикалами, выбор модели |
| **3. Дуэль агентов** | Генератор гипотезы vs Критик (проверка по Unihan/CHISE) |
| **4. Модели** | реестр чекпойнтов + горячее переключение детектора/матчера/LLM |
| **5. Обучение** | фоновые задачи (sanity-loss / эмбеддинги / детектор) + живой лог |
| **6. Данные** | реестр датасетов + разметка боксов (авто-детекция → YOLO) |
| **7. Eval+Настройки** | честный eval, пересборка банков, показ конфига |

HTTP API: `/api/decode_photo`, `/api/system_status`, `/api/agent_duel`, `/api/config`,
`/api/models`, `/api/models/switch`, `/api/train[/status|/list]`, `/api/datasets`,
`/api/eval`, `/api/rebuild`, `/api/label/export`.

## 🧠 Как это работает (кратко)

```
фото → препроцессинг (бинаризация Сауволы, инверсия эстампажа)
     → сегментация знаков (свиток/строка)
     → детекция компонентов (RT-DETR / пиксельный рекурсивный разбор)
     → опознание компонентов (Chamfer+HOG с калибровкой / эмбеддинги)
     → сборка структуры IDS (⿰⿱⿲…) + прямое опознание целого знака
     → дедукция по 六书 (значение + чтение MC/OC)
     → grounded-контекст из графа знаний
```

## 📊 Честные метрики (замерено)

| Метрика | Значение |
|---|---|
| round-trip разбора IDS (CHISE) | **1.0000** (163 059 композитных записей) |
| honest eval top-1 | **0.978** (синтетические деградации) |
| false accept (мусор → знак) | **1.7%** (3/180) |
| калибровка уверенности | acc 0.9912 / prec 0.9991 |

> ⚠️ Эти цифры — «потолок» на синтетике. Честные метрики на живых музейных фото
> появятся после обучения детектора на OBIMD.
